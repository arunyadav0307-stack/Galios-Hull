# Phase 4 deliverable — Constituent enumerator formula

**Status: the orbit-product formula is now a theorem with a complete proof.** It was previously only
verified numerically (24/24 in `phase2/r1_probe/r1_orbit_check.py`). This document supplies the proof
the blueprint requires (*"Prove local choices are independent before multiplying their generating
polynomials"*), and states precisely what is and is not new.

This upgrades an observation to a theorem. It does **not** create novelty: the formula is the
field-level hull-dimension enumerator, which is prior art in the square-free case (Debnath–Prakash–Islam
2023; Sangwisut–Jitman–Udomkavanich 2017) and is a routine consequence of the source's Theorem 8 in the
repeated-root case. That is exactly why R1 was recorded NO-GO.

---

## 1. Setting and hypotheses

* `F = F_{q²}`, `q = p^m`, `p = char F`.
* `n ≥ 1` **arbitrary**, including `p | n` (repeated-root regime). Write `n = p^v n'`, `gcd(n',p) = 1`.
* `α ∈ F^*` with **`α^{q+1} = 1`** — the source's standing hypothesis (`r | q+1` for `r = ord α`).
  This is used only in Lemma 2, and it is what makes the Hermitian dual of an `α`-constacyclic code
  again `α`-constacyclic.
* `f := x^n − α ∈ F[x]`, `R := F[x]/(f)`.
* Conjugate-reciprocal involution on polynomials with nonzero constant term:
  `g^†(x) := x^{deg g} \overline{g(1/x)}`, where `\bar{⋅}` is `z ↦ z^q`. It satisfies `(gh)^† = g^†h^†`
  and `g^{††} = g`.
* Hermitian form on `F^n`: `⟨x,y⟩_H = Σ_i x_i y_i^q`.
* For a monic divisor `g | f`, `C_g := (g)/(f) ⊂ R`, the `α`-constacyclic code generated by `g`.
* `Hull_H(C) := C ∩ C^{⊥_H}`, `h(C) := dim_F Hull_H(C)`.
* The constituent enumerator `H_α(z) := Σ_{g | f, g monic} z^{h(C_g)}` — **counting distinct codes**
  (see Lemma 1), not generator descriptions.

## 2. Lemma 1 (codes ↔ monic divisors, bijectively)

**Claim.** `g ↦ C_g` is a bijection from the set of monic divisors of `f` to the set of
`α`-constacyclic codes of length `n` over `F`.

*Proof.* `R` is a principal ideal ring (`F[x]` is a PID and `R` is a quotient), so every ideal is
principal; every ideal of `R` is generated by a divisor of `f` in `F[x]`. If `C_g = C_{g'}`, then
`(g) = (g')` in `R`, so `g = ug' + sf` for suitable `u, s`; reducing the identity `g = ug' mod f` and
using `deg g, deg g' < deg f` with `g, g'` monic and dividing `f` gives `g = g'`. Surjectivity is
immediate. ∎

**Consequence for counting.** Distinguishing codes is *identical* to distinguishing monic divisors; no
generator description is over- or under-counted. This settles the blueprint's §3A requirement
("distinguish counting codes from counting generator-polynomial descriptions") for the field level.
It was also checked exhaustively by brute force over **all** subspaces in the `q = 3, n = 3` case
(`phase2/r1_probe/r1_probe.py`: 184 subspaces, 8/8 values of `α` matched).

## 3. Lemma 2 (uniform multiplicity, and `†` permutes the factors)

**Claim.** (a) Every irreducible factor of `f = x^n − α` occurs with multiplicity exactly `p^v`.
(b) `f^† ∝ f`, so `†` permutes the set of irreducible factors of `f`.

*Proof.* (a) `F` is perfect, so `α` has a unique `p^v`-th root `c`; in characteristic `p`,
`x^{p^v n'} − c^{p^v} = (x^{n'} − c)^{p^v}`, so `f = (x^{n'} − c)^{p^v}`. The derivative of
`x^{n'} − c` is `n'x^{n'−1} ≠ 0` with `x ∤ (x^{n'} − c)`, and `gcd(n',p) = 1`, so `x^{n'} − c` is
squarefree. Hence each of its irreducible factors occurs in `f` with multiplicity exactly `p^v`.

(b) `f^† = x^n \overline{f(1/x)} = x^n(\overline{x^{-n}} − \bar α) = 1 − \bar α x^n`, and
`\bar α = α^q = α^{q+1}α^{-1} = α^{-1}` by hypothesis, so `f^† = 1 − α^{-1}x^n ∝ x^n − α = f`. Since
`†` is multiplicative and involutive, it maps irreducible factors of `f` to irreducible factors of
`f^† ∝ f`, i.e. permutes them. ∎

**Remark.** Part (a) is what makes a *uniform* exponent box correct for all `n`; it is the structural
content behind the source's `p^v` bounds. Part (b) fails without `α^{q+1} = 1`, which is why that
hypothesis is stated rather than inherited silently.

## 4. Lemma 3 (conjugate-reciprocal action is an involution on factors)

**Claim.** Write the distinct irreducible factors of `f` as `g_1, …, g_s`. There is an involutive
permutation `σ` of `{1,…,s}` and nonzero scalars `u_i` with `g_i^† = u_i g_{σ(i)}`; moreover
`deg g_i = deg g_{σ(i)}`.

*Proof.* By Lemma 2(b), `g_i^†` is an irreducible factor of `f` up to a nonzero scalar, giving `σ`.
Since `†` is involutive, `σ` is involutive. `†` preserves degree. ∎

## 5. Lemma 4 (the lcm, and the key max-sum identity)

Let `g = ∏_i g_i^{a_i}` with `0 ≤ a_i ≤ p^v`, and `h = f/g = ∏_i g_i^{p^v − a_i}`.

**Claim.**

```
(i)   h^† = (unit) · ∏_j g_j^{p^v − a_{σ(j)}}
(ii)  lcm(g, h^†) = ∏_j g_j^{ M_j },        M_j := max(a_j, p^v − a_{σ(j)})
(iii) deg lcm = Σ_j m_j M_j,               m_j := deg g_j
(iv)  h(C_g) = Σ_j m_j (p^v − M_j)
```

*Proof.* (i) is Lemma 3 plus multiplicativity. (ii) holds because the `g_j` are pairwise coprime, so
the lcm of two products of powers of the same irreducibles has exponent the pointwise maximum. (iii)
follows. (iv): the Hermitian dual of `C_g` is `C_{h^†}` (source p. 5, under `α^{q+1}=1`), and
`Hull_H(C_g) = ⟨lcm(g, h^†)⟩` (source p. 5, citing [34, Thm 1]); a code generated by a divisor `ℓ` of
`f` has dimension `n − deg ℓ`; so `h(C_g) = n − deg lcm`, and `n = Σ_j p^v m_j`. ∎

**Max-sum identity.** For integers `A, B ∈ [0, e]`:
`max(A, e−B) + max(B, e−A) = max(A+B, 2e−A−B)`.

*Proof.* If `A + B ≤ e` then `A ≤ e−B` and `B ≤ e−A`, so the left side is `(e−B)+(e−A) = 2e−(A+B)`,
and `2e−(A+B) ≥ A+B` since `A+B ≤ e`. If `A + B ≥ e` then both maxima are `A` and `B`, giving
`A+B`, and `A+B ≥ 2e−(A+B)`. ∎

## 6. Theorem (orbit-product form of the constituent enumerator)

Decompose `{1,…,s}` into the orbits of `σ`. Then

```
H_α(z)  =  ∏_{orbit O}  P_O(z),
```

with the local polynomials

| orbit type | `P_O(z)` |
|---|---|
| **fixed point** `O = {i}` (i.e. `g_i^† ∝ g_i`) | `P_i(z) = Σ_{a=0}^{p^v} z^{ m_i · min(a, p^v − a) }` |
| **2-cycle** `O = {i, j}`, `σ(i)=j` | `P_{ij}(z) = Σ_{a,b=0}^{p^v} z^{ m_i · min(a+b, 2p^v − a − b) }` |

In particular `H_α(1) = ∏_{O} (p^v + 1)^{|O|/|O|} … = (p^v + 1)^{s}`; more precisely each orbit of
size 2 contributes `(p^v+1)^2` and each fixed point `(p^v+1)`, so the number of `α`-constacyclic codes
of length `n` is `(p^v + 1)^s`, where `s` is the number of distinct irreducible factors of `x^n − α`.

*Proof.*

**(a) Bijection onto the exponent box.** By Lemma 1 the codes are exactly the `C_g` for monic `g | f`,
and by Lemma 2(a) each such `g` is uniquely `∏_i g_i^{a_i}` with `0 ≤ a_i ≤ p^v`. Unique
factorisation makes `(a_1,…,a_s) ↦ g` a bijection onto the box `[0,p^v]^s`. Hence

```
H_α(z) = Σ_{(a_i) ∈ [0,p^v]^s} z^{h(C_{(a_i)})}.
```

**(b) Additivity over orbits.** By Lemma 4(iv) and (ii),

```
h(C_g) = Σ_j m_j (p^v − max(a_j, p^v − a_{σ(j)})).
```

For a fixed point `σ(j) = j` the summand is `m_j(p^v − max(a_j, p^v − a_j)) = m_j min(a_j, p^v − a_j)`.
For a 2-cycle `{i,j}`, the two summands combine, using the max-sum identity with `e = p^v`:

```
m_i(p^v − max(a_i, p^v − a_j)) + m_j(p^v − max(a_j, p^v − a_i))
  = m_i( 2p^v − max(a_i + a_j, 2p^v − a_i − a_j) )        (using m_i = m_j, Lemma 3)
  = m_i · min(a_i + a_j, 2p^v − a_i − a_j),
```

which depends on the pair only through `a_i + a_j`. So `h(C_g)` is a **sum over orbits** of a function
of the exponents belonging to that orbit.

**(c) Independence, and why the product is legitimate.** The box `[0,p^v]^s` is a Cartesian product
`∏_O [0,p^v]^{|O|}`, *and* the exponent coordinate of every factor is a free coordinate of `g` — the
constraint linking factors is only that each factor of `f` occurs with multiplicity at most `p^v`, and
that bound is per-factor. There is no cross-factor constraint: any assignment of exponents in the box
gives a divisor of `f`, hence (Lemma 1) a distinct code. This is the point the blueprint requires to be
proved rather than assumed: **the admissible set is exactly a product of per-orbit sets.**

Combining (a)–(c): the sum over `∏_O [0,p^v]^{|O|}` of a product `∏_O z^{(orbit contribution)}`
factors as `∏_O (Σ_{exponents on O} z^{(orbit contribution)})`, which is the stated product, with the
two orbit types giving the two stated polynomials. `H_α(1)` follows by evaluating at `z = 1`. ∎

## 7. Consequences

1. **Exactness, not approximation.** `H_α` is a polynomial of degree `≤ ⌊n/2⌋` with nonnegative
   integer coefficients summing to `(p^v+1)^s`. Every coefficient counts distinct codes.
2. **Uniform treatment of repeated roots.** Nothing above assumes `gcd(n,p) = 1`; the repeated-root
   case is the generic case `v ≥ 1`, and Lemma 2(a) is what makes it work. The square-free case is
   `p^v = 1`, where the boxes are `[0,1]^s` and every local polynomial is `1 + z^{m_i}` (fixed) or
   `1 + 2z^{m_i} + z^{2m_i}` (2-cycle) — i.e. `(1 + z^{m_i})^2`.
3. **Relation to the source's Theorem 8.** The source writes the dimension as
   `Σ_{j∈Ω} ord_j(q²)a_j + Σ_{j∈Ω'} ord_j(q²)b_j` with the box bounds `2γ(j)⌊p^v/2⌋` and `2β(j)p^v`,
   grouping factors by cyclotomic coset. The theorem above is the same statement resolved per
   `σ`-orbit, which is what makes it a generating function rather than a set of attainable dimensions.
   It is therefore a **routine refinement**, not a new result — consistent with the R1 NO-GO verdict.
4. **What it does not give.** No distance, and hence no joint `(hull, d)` law. `H_α` is the *marginal*
   in the hull dimension. The joint law is not a product (P3-1 §4, C3 5/5) and is not obtained here.
